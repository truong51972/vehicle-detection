# Figures

No figures are fabricated or copied into the scaffold. When inserting a figure:

1. Pin its source (dataset/video/image, model, branch, run, config, GT vs prediction).
2. Prefer reproducible image-processing visualizations (histogram/luminance/edge/ROI) and paired per-class comparisons.
3. Distinguish illustrations, GT boxes and **real** predictions in the caption.
4. Use Quarto `#fig-...` labels and `@fig-...` cross-references; avoid screenshots of unreadably small training plots.
5. Do not import images or code with unclear licenses/rights.
